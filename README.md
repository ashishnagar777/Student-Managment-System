# Student Management System

A Spring Boot based web application designed to manage student records efficiently using CRUD operations.

## 🚀 Features
- Add, update, delete, and view students
- Clean UI using Thymeleaf & Bootstrap
- REST APIs documented with Swagger
- MVC layered architecture

## 🛠 Tech Stack
- Java
- Spring Boot
- Spring MVC
- Spring Data JPA
- Hibernate
- Thymeleaf
- MySQL
- Maven
- Swagger(OpenAPI)

## 📂 Architecture
- Controller Layer
- Service Layer
- Repository Layer
- Entity Layer

## 🎯 Learning Outcome
- Practical experience with Spring Boot
- Understanding MVC architecture
- Database interaction using JPA & Hibernate
- API documentation using Swagger
